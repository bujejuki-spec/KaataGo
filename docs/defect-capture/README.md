# Capture temuan

Simpan tangkapan layar temuan di folder ini, satu berkas satu temuan,
dinamai memakai ID temuannya:

    DF-001.jpg
    DF-002-sebelum.jpg
    DF-002-sesudah.jpg

Lalu tulis nama berkasnya di kolom **Capture** pada lembar Defect di
`TEST-CASE-KAATAGO.xlsx`. Kolom **Buka Capture** di sebelahnya berubah
jadi tautan yang bisa diklik.

Nama berkas dipakai sebagai penghubung, bukan gambarnya ditempel ke
dalam xlsx: satu tangkapan layar HP berukuran 300–800 KB, dan tiga puluh
temuan berarti berkas Excel yang terlalu berat untuk dikirim lewat chat
mana pun.
